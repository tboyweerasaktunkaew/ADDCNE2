# GridOps PEA - ระบบบริหารแผนงานดับไฟและปฏิบัติการระบบไฟฟ้า ศูนย์ควบคุมการจ่ายไฟฟ้า

เว็บแอปพลิเคชันบริหารจัดการแผนงานดับไฟ ปฏิบัติการระบบไฟฟ้า และประสานงานโรงไฟฟ้า VSPP / กฟผ. สำหรับ **ศูนย์ควบคุมการจ่ายไฟฟ้า (Grid Control Center)** ออกแบบด้วยสถาปัตยกรรมแบบ **Multi-page Views (SPA Routing) ไม่มีหน้าต่าง Popup/Modal ซ้อนทับ** เหมาะสำหรับการใช้งานบนหน้าจอคอมพิวเตอร์ในศูนย์ควบคุม พร้อมระบบตรวจจับ Feeder Conflict อัตโนมัติและระบบพิมพ์เอกสารราชการขนาด A4

---

## 1. คุณสมบัติเด่นของระบบ (Core Features)

1. **สถาปัตยกรรมแยกหน้าอิสระ (Zero Popups/Modals)**:
   - **หน้าที่ 1: Dashboard / รายการแผนงาน**: ตารางความหนาแน่นสูง ค้นหา กรองสถานะ/กฟฟ./วันที่ และสรุปสถานะ Conflict
   - **หน้าที่ 2: ฟอร์มเพิ่ม/แก้ไขงาน (Full-Page Form)**: จัดการงานระดับ Job_ID และเพิ่ม/ลบวันปฏิบัติงาน (Sub_ID) ได้อิสระ (ข้ามวันได้) พร้อมช่องกรอก `Custom_Detail` รายวัน และระบบตรวจจับ Conflict แบบ Real-time ทันทีขณะพิมพ์
   - **หน้าที่ 3: มุมมองปฏิทิน & คอนฟลิกต์ (Calendar & Conflict Inspector)**: ปฏิทินรายเดือน/สัปดาห์ พร้อมแถบตรวจสอบเวลาดับไฟ 06:00-18:00 น. และระบบแจ้งเตือนฟีดเดอร์ซ้อนทับอัตโนมัติ
   - **หน้าที่ 4: พิมพ์เอกสารราชการ A4 (Print & PDF Center)**: รองรับการออกเอกสาร 3 ประเภท:
     1. *ใบปะหน้าสรุปแผนงานประจำวัน* (ดึง Sub_ID, Custom_Detail, ขอบเขต และ 4 ช่องลงนาม)
     2. *หนังสือแจ้งปลดสวิตช์ขนานโรงไฟฟ้า VSPP* (ดึงข้อมูล VSPP_Master อัตโนมัติ)
     3. *ใบแจ้งประสานงานดับไฟสถานีไฟฟ้า กฟผ.* (EGAT Coordination)
   - **หน้าที่ 5: จัดการข้อมูล Master (Master Data Management)**: จัดการชีต `VSPP_Master` และ `PEA_Master`
   - **หน้าที่ 6: คู่มือเชื่อมต่อ Google Sheets & GitHub Pages**: จัดการ Web App URL, ทดสอบการเชื่อมต่อสด และคัดลอกโค้ด GAS ได้ใน 1 คลิก
2. **ระบบตรวจจับ Feeder Conflict อัตโนมัติ**:
   - ตรวจสอบงานที่มีช่วงเวลาคาบเกี่ยวกันบน **ฟีดเดอร์หลักเดียวกัน (Same Feeder)**
   - ตรวจสอบงานที่กระทบต่อ **ฟีดเดอร์ฝากโหลด (Guest Feeder Overlap)**
3. **ระบบสิทธิ์ผู้ใช้งาน (Role-Based Access Control)**:
   - **Admin**: เพิ่ม/แก้ไข/ลบงาน, ปรับปรุงสถานะภาพรวมและรายวัน, จัดการข้อมูล Master
   - **Viewer**: ดูข้อมูล ตรวจสอบปฏิทินและ Conflict และพิมพ์เอกสารได้อย่างเดียว

## 3. ขั้นตอนการตั้งค่า Google Apps Script Web App

1. สร้าง Google Sheets ใหม่ ตั้งชื่อชีตว่า `Tasks`, `VSPP_Master`, และ `PEA_Master`
2. ไปที่เมนู **ส่วนขยาย (Extensions)** > **Apps Script**
3. คัดลอกโค้ดจากไฟล์ `/gas/Code.gs` ในโปรเจกต์นี้ไปวางแทนที่โค้ดเดิม
4. กดบันทึก (Ctrl + S)
5. คลิกปุ่ม **ทำให้ใช้งานได้ (Deploy)** > **การทำให้ใช้งานได้ใหม่ (New deployment)**
6. เลือกประเภท: **เว็บแอปพลิเคชัน (Web app)**
   - **เรียกใช้ในฐานะ (Execute as)**: `ฉัน (Me)`
   - **ผู้มีสิทธิ์เข้าถึง (Who has access)**: `ทุกคน (Anyone)` *(สำคัญมาก)*
7. กด **ทำให้ใช้งานได้ (Deploy)** และคัดลอก **Web app URL**
8. เปิดหน้าเว็บแอปพลิเคชัน เมนู **"คู่มือ & Google Sheets"** แล้ววาง URL ในช่องแล้วกด **"บันทึก & ทดสอบเชื่อมต่อ"**

## 4. ขั้นตอนการ Deploy ขึ้น GitHub Pages

### วิธีที่ 1: ใช้ GitHub Actions อัตโนมัติ (แนะนำ)
ไฟล์ `.github/workflows/deploy.yml` ได้ถูกตั้งค่าไว้เรียบร้อยแล้ว:
1. นำโค้ดขึ้น GitHub Repository
2. เข้าไปที่ **Settings** > **Pages**
3. ในส่วน **Build and deployment > Source** ให้เลือกเป็น **GitHub Actions**
4. ทุกครั้งที่ push โค้ดขึ้น branch `main` ระบบจะทำการ build และ deploy ขึ้น GitHub Pages ให้อัตโนมัติ

### วิธีที่ 2: Build แบบ Manual
```bash
npm run build
```
นำไฟล์ทั้งหมดในโฟลเดอร์ `dist/` ไปอัปโหลดขึ้น branch `gh-pages` หรือ root ของ GitHub Pages
